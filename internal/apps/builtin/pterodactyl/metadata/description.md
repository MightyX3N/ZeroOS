Pterodactyl runs game servers for you: Minecraft, Valheim, Garry's Mod, Rust, Terraria and many more. Every server lives in its own container, with a console, a file manager and backups in the browser.

ZeroOS sets it up completely: your account, this mini PC as the place servers run on, and a set of ports (25565 to 25600) for your first servers. After installing, sign in and create a server.

To let friends join a server from outside your home, share its port in ZeroOS: Settings › Sharing online › Share a port.
